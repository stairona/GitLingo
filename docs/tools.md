## Tools for this project

| Tool | What it does for us | Part |
|---|---|---|
| Node.js + npm | Runs and installs the project (install from nodejs.org beforehand) | Setup |
| Vite + React | The app framework: fast dev server, component-based UI | Frontend |
| Plain CSS | Styling. A dark theme is just a few CSS variables | Frontend |
| JSON files | Lesson content, so no database is needed | Data |
| localStorage | Saves which lessons you finished, right in the browser | Data |
| Claude Code | Each of us uses our own to learn, debug and review | Dev tool |
| GitHub + Vercel | The repo, plus a free auto-deploy on every push to `main` | Hosting |
